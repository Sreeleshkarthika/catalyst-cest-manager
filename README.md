# CATALYST CEST & Unit Test Performance Manager

A mobile-first PWA for CATALYST examination management.

## Included
- CEST mark entry and automatic ranking
- CEST average and subject-wise analysis
- Unit Test management
- Student performance trends
- CEST vs Unit Test analysis
- Premium student/parent report
- PDF report generation
- WhatsApp sharing workflow
- JSON backup and restore
- Offline PWA support
- CATALYST one-line app icon

## Run locally
Open `index.html` in a browser for the basic local version.

For full PWA installation/offline service-worker behavior, host the folder over HTTPS (for example GitHub Pages).

## GitHub Pages
1. Upload all files in this folder to the repository root.
2. GitHub → Settings → Pages.
3. Select **Deploy from a branch**.
4. Select the main branch and `/ (root)`.
5. Save.
6. Open the generated Pages URL on the phone.
7. Use the browser's **Add to Home screen / Install app** option.

## Data
The app stores working data in browser LocalStorage. Data does not automatically sync between devices. Use the built-in JSON Backup/Restore for transfer.
